The reason i made this package is to make setting up hardware easier

For example, I made it so instead of having to type 10 lines of code
setting up a single motor in the main OpMode class (making it super
messy and unreadable) I made a class that we initialize that already
has most of the things we need to set up done for us. If we need to change
something specific use a method that I added OR add a new method if
I didn't add a method that would change what you need to change yet.
